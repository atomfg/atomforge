# atomforge-testing

Shared pytest contracts for AtomForge plugin packages.

See [Testing a model plugin](https://atomfg.github.io/atomforge/development/plugin-testing/)
for the minimal wiring pattern, and [How the plugin tests work](https://atomfg.github.io/atomforge/development/plugin-tests/)
for what the contracts check and how. The [model plugin template](../../templates/model-plugin/) is a complete,
tested plugin; its [tests/test_contracts.py](../../templates/model-plugin/tests/test_contracts.py)
is a copy-pasteable test module.
